## Regras aplicadas

- Uma página por intenção principal, com as variações naturais dela. Não há e não
  deve haver páginas separadas para “advogado Ariquemes” e “advogado em
  Ariquemes”.
- Consultas de questão vão para **artigos**, que linkam para a página da área —
  nunca para uma página de área duplicada por palavra-chave.
- Nenhuma página por cidade vizinha foi criada. Só faz sentido se houver
  atendimento real e conteúdo próprio sobre aquela praça; repetir o mesmo texto
  trocando o nome da cidade é exatamente o que não se deve fazer.
- A quantidade de linhas aqui organiza a pesquisa. Não obriga a criar 22 páginas.
